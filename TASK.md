**Лабораторная работа №10**  
**Дисциплина:** Программирование на Python  
**Тема:** Разработка ML-сервиса для предсказания одобрения ипотеки  
**Цель работы**  
Освоить полный цикл разработки прикладного ML-сервиса: от обработки данных и обучения модели до создания API и пользовательского интерфейса.  
**Описание задания**  
Необходимо разработать консультирующий сервис, который предсказывает вероятность **одобрения или отказа в выдаче ипотеки** на основе предоставленных данных клиента.  
Сервис должен быть реализован в виде веб\-приложения с использованием **FastAPI**, предоставляющего API для взаимодействия с моделью машинного обучения.  
**Исходные данные**  
Для обучения модели использовать [датасет](https://drive.google.com/open?id=1ToMohhfusu4S42dBpDWfKYQhSW0IDrhi)  
**Функциональные требования**  
Сервис должен предоставлять следующие API-методы:  
**1\. Обучение модели**  
**POST /upload-model**  
Принимает:

* модель в формате pkl

Возвращает:

* статус загрузки (успешно / ошибка) 

**2\. Получение предсказания**  
**POST /predict**  
Принимает:

* одну или несколько записей (строк) с коррелирующими признаками клиента (те признаки, которые остались после предобработки данных)

Возвращает:

* массив с коррелирующими признаками и loan\_status(одобрено или отказ)  
* Кидает ошибку, если модель не загружена

**3\. Получение предсказания**  
**POST /predict-from-csv**  
Принимает:

* обычный csv полученный из train\_test\_split без предобработки или предобработанный csv

Возвращает roc\_auc (если был передан loan\_status) и полный датасет с predicted loan\_status

* 

**Требования к реализации**  
**1\. Обработка данных**

* Очистка данных (пропуски, выбросы)   
* Кодирование категориальных признаков   
* Масштабирование (при необходимости)   
* Разделение на train/test   
* Отбор признаков (feature selection) 

**2\. Модель машинного обучения**

* Реализовать и сравнить не менее 2 алгоритмов (например):   
  * логистическая регрессия   
  * случайный лес   
  * градиентный бустинг   
* Выбрать лучшую модель по метрике ROC-AUC   
* Сохранить обученную модель 

**3\. Backend (API)**

* Реализовать сервис на FastAPI   
* Организовать:   
  * загрузку и обучение модели   
  * сохранение и загрузку модели   
  * обработку входных данных   
* Обеспечить обработку ошибок 

**4\. Frontend**

* Реализовать простой интерфейс (например, HTML/JS или React), позволяющий (разрешается вайбкодинг, но требуется предоставить все промпты):   
  * вводить данные клиента   
  * получать предсказание   
* Допускается минималистичная реализация 

**Организация работы (командный проект)**  
Команда состоит из 2-3 человек:

1. **ML Engineer**   
   * Выбор и обучение моделей   
   * Оценка качества   
   * Сериализация модели   
   * Предобработка данных   
   * Feature engineering и отбор признаков   
2. **Backend Developer**   
   * Реализация API на FastAPI   
   * Интеграция модели   
   * Обработка запросов   
3. **Frontend Developer** (опционально в случае вайбкодинга)  
   * Разработка пользовательского интерфейса   
   * Интеграция с API
